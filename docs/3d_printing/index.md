# Introduction

The 3D printing workshop will have two parts:

* 3D Models - Tuesday, 04 August, 10:30 - 12:00
* 3D Hardware - Saturday, 08 August, 10:30 - 12:00

The workshop is dedicated to all participants, and you do not need prior knowledge, as it is suitable for beginners.

# 3D Models

During the workshop, you will learn about:

* How 3D printing works
* What a slicer is and how to use it
* How to 3D model a simple object
